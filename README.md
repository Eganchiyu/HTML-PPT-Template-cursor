# HTML Deck Presentation Framework

<p align="center">
  <b>一套面向学术与专业汇报的高端 1920×1080 网页演示模板系统</b><br>
  零第三方构建依赖 | 模块化源码 | 离线编译 | 沉浸式大屏放映
</p>

## ✨ 核心特性

* 🏗 **模块化架构**：摒弃传统单文件 HTML，采用 Python 脚本 (`build.py`) 将分散的 `slides/*.html` 动态编译为单文件，支持多章节组合。
* ⚡ **极速实时预览**：内置零依赖 Live Reload 服务，保存源文件（HTML/CSS/JS）即刻刷新页面，支持双屏演讲者视图同步。
* 🎨 **高端视觉系统**：基于 Reveal.js 深度定制的 1920×1080 纯净画幅。内含 Bento 布局、毛玻璃卡片、微动效背景层、数据统计仪表盘及图表重放动效。
* 🔍 **极致交互细节**：
  * **Spring Hover Popout**：图片悬停即刻“Duang~”弹出完整原图。
  * **全屏 Lightbox**：点击即可锁定全屏查看细节，完美支持超长纵向截图滚动。
  * **Cyber Swarm 序幕**：独家开屏构建动画，光标协作汇聚，拉满开场仪式感。
* 🔌 **完全离线运行**：所有字体（Inter, JetBrains Mono）与依赖库均本地化，摆脱网络环境束缚，放映更从容。

## 🚀 快速开始

环境要求：`Python 3.x` 及 `Google Chrome` 浏览器。无须安装 npm 或任何 Python 第三方库。

### 1. 开发与实时预览
```bash
# 启动本地预览服务器（默认端口 8080）
python3 build.py --serve

# 指定其他端口
python3 build.py --serve -p 8800
```
启动后在浏览器打开 `http://127.0.0.1:8080`。修改 `slides/` 下的 HTML、`custom.css` 或 `custom.js`，浏览器会自动刷新。

### 2. 静态编译与资源校验
```bash
# 仅执行合并编译，并检测 assets 下的本地媒体资源是否缺失
python3 build.py
```

### 3. 正式放映
```bash
# 执行全屏放映（将以独立 App 模式启动 Chrome，屏蔽无关干扰）
./present.sh

# 从特定页面（如第 4 页）开始放映
./present.sh 3
```

> **放映快捷键**：
> * `→` / `←`：前进 / 后退
> * `S`：开启演讲者视图（查看备注及计时器）
> * `O`：全局幻灯片总览模式
> * `F`：全屏切换
> * `I`：（在封面页）重播开屏构建动画
> * `Esc`：退出放映/关闭全屏图片

## 🎨 主题与样式定制

本模板的主题色高度可控。如需更改配色，请务必同步修改以下三处，避免新旧样式混搭：

1. **CSS 色板**：修改 `styles/custom.css` 中的 `:root` 变量（主要修改 `--bg-base`, 文字深色系列及 `--accent-*` 三主色）。
2. **JS 动画配置**：修改 `scripts/custom.js` 中的 `AGENTS_DATA`（更改开屏光标的名字与颜色）以及 `buildStage()` 内联的中心徽标 SVG 颜色。
3. **幻灯片内联资源**：修改 `slides/*.html` 中写死的内联 SVG 颜色（如闭环示意图、图例等）。

*注：本套设计系统基线为 **亮色系**，强调留白与高对比度排版。如非绝对必要，不建议强行反转为深色暗黑主题。*

## 📏 版式与排版规范

本模板秉持“克制与专业”的排版理念：
* **拒绝局促**：页面文字块左右需留足 34–44px 内边距，页面边缘留白 86px。
* **字号基准**：正文不小于 20px（行高 1.9），页面标题固定 54px。CSS 已利用 `!important` 锁定基准视觉，**请勿在 HTML 中写内联字号强行缩小文字**。
* **控制密度**：一页一个核心焦点；文案冗长时请精简修辞或拆分页面；纯文字页面连续不超过两页。
* **专业表达**：建议全篇**零 Emoji**，克制使用口语化与网感修辞。
